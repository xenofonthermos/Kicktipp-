# Bundesliga-Kicktipp-Prognose – Daten

Automatisch generierte Tippempfehlungen für eine private Kicktipp-Spassrunde. Kein eigener Code, nur Ausgabedaten der Prognose-Engine.

- `predictions.json` — von der Flutter-App abgerufene, maschinenlesbare Prognose für den aktuellen Spieltag
- `predictions.md` — dieselben Daten menschenlesbar, direkt für Kicktipp verwendbar

Die Prognose ist reiner Unterhaltungswert, keine Wett- oder Anlageempfehlung, keine Garantie auf Richtigkeit. Erzeugt durch das Backend im privaten Projekt `Bundesliga-Kicktipp-Prognose`.
